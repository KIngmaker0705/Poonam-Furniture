# Poonam Furniture And Electronic — Demo Website

Design demo of the showroom website (Jalna, Maharashtra). Static version hosted on GitHub Pages.

- Products, categories and offers are bundled in the site.
- Cart, order requests and contact form work as a demo (saved only in the visitor's own browser).
- Admin dashboard is not part of this public demo.

## Run locally
```
npm install
npm run dev
```

## Deploy
Push to `main` — the GitHub Action in `.github/workflows/deploy.yml` builds and publishes automatically.
In the repo: **Settings → Pages → Source: GitHub Actions**.
